# ASCII AZUR 0.28.0 — Guardian & Three Lessons

## Gameplay delivered
- Authored three-element mastery lessons in Arken: each first distinct win yields 55 additional party XP, finite save-backed flags and once-only 2-tonic reward from Iria.
- Guardian preparation now includes a conscious-party leader selector with real equipped-move damage recommendation, preserving team order and the v1 battle checkpoint.
- Hollowhart's Ether signature Eclipse is exclusively used with its existing clearly telegraphed charged attack, making Guard meaningful and removing early unannounced type-counter bursts.
- Saved campaigns, deterministic route placements, persistent crypt and both original rendering profiles remain unchanged.

## Acceptance and limitations
- A reproducible end-to-end computational combat harness checks 12 deterministic seeds for each starter, with earned captures and XP, bounded three-lesson preparation, regular battle actions, guardian guard timing, crypt physical traversal and v1 reload. Gate: >=11 Guardian and crypt completions per 12-seed cohort.
- Scope is combat pacing and crypt movement. Surface portal navigation is driven via established interaction handlers, not a human exploration playthrough. Real-device FPS, real player quality, global authored campaign and public external HTTP smoke are separate unfinished milestones.
- Compile, 4 Chromium renderer/backend profiles, PWA audit, GitHub Pages provenance and run URLs must be appended to persistent evolution state only after completed CI/deployment verification.

## Compatibility
- No save version bump: new lesson flags are optional and idempotent.
- Offline cache v028-q01 and page label v0.28 track the semantic release.
