# v0.66.0 — Pilgrim's field trails

## Player-facing completed epic
- Seven named regional three-act discovery journeys, each drawn exclusively from existing real landmarks, narrative interactions or roaming witnesses. No extra region, quest treadmill, content gate or currency.
- Journal shows three distinct acts, completed meaning, current progress, spoiler-safe unknown steps, and action to track an already revealed and actionable site using the existing persistent compass.
- Completing three acts returns the player to that region's already visited Lumbre. A committed single-use flag and existing tactical relic grant create a usable reward. Region-specific authored recognition remains visible afterward.
- Rewards: village Hearth Bead, forest Ember Tooth, sanctuary Mist Pearl, marsh Root Knot, spire Echo Prism, ossuary Pilgrim Ward, garden Hearth Bead; finite +20 to +60 Echoes. A capped preferred relic falls back to another existing uncapped relic; all capped => story/Echoes only.
- All acts are derived from actual save-v1 flags and world progression, so older saves automatically recognize earned steps; no migration, online dependency or unseen-coordinate disclosure.
- Transaction uses existing writeSave optimistic primary/backup scheme. Storage failures, stale tabs, combat, crypt, expeditions, distant or unvisited Lumbres, 200-flag cap and capped currencies reject without live changes.
