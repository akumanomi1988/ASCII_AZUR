# Arquitectura / Architecture

**Source of truth:** `src/**/*.ts`, not `play.html` or `dist/`.

- Game rules: `domain.ts`, `combat/`, `creatures/`, `party.ts`, `rpg.ts`.
- Persistent procedural content: `world/`, `dungeons/`, `expeditions/`.
- Presentation: `render.ts`, `dungeons/draw-dungeon.ts`, `dungeons/room-art.ts`, `actors/`, `audio.ts`.
- App flow (technical debt): `main.ts`. Extract per-scene controllers iteratively, with regression tests; do not rewrite simultaneously.
- Distribution: `index.html` loads ES modules; GitHub Pages publishes static modular assets (`index.html`, `style.css`, `dist/`, PWA, icon) on `gh-pages`. The standalone `play.html` is generated by CI and delivered as an artifact, not committed. `sw.js` caches imports.

## Invariants
1. Deterministic seeded generation; no changes to saved topology or existing dungeon schema without a migration.
2. Presentation never alters simulation/collision data.
3. Saves exportable; old `version:1` saves remain readable.
4. `npm run verify` must pass before release.
5. Android horizontal is the primary interaction layout; web remains a first-class platform.
